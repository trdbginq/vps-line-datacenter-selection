## 先看懂线路，再谈价格

国内访问海外机器，走的是三大运营商的国际出口，出口本身分档次：

**AS4837（联通普通线路）** 相当于国道。价格便宜、带宽给得足，白天够用，晚高峰容易堵。

**AS9929（联通精品线路）** 是 4837 的升级版，路更宽更直，晚高峰表现稳定得多，价格只贵一点点，圈内公认的性价比选择。

**CN2 GIA（电信高端线路）** 是电信的 VIP 通道，三网回程都能受益，延迟和稳定性在第一梯队，价格也在第一梯队。

**CMIN2（移动精品线路）** 主要服务移动宽带用户，移动访问延迟特别低。

日本方向常用软银或 BGP 优化组合，亚太延迟比美国近一大截。

落到选择上只有一句话：**电信用户优先看 CN2 GIA，联通用户优先看 9929，移动用户优先看 CMIN2**。预算紧就退一档到 9929 或 4837；亚太低延迟需求看日本、香港节点。

香港机房的卖点是延迟，ping 值普遍在 30–60ms，面向国内用户建站，体感接近国内主机。香港的国际线路（无大陆优化）延迟就明显高一截，便宜也是这个原因。

看线路时还有一个容易被忽略的坑：**共享带宽不等于独享带宽**。行业里常见的做法是「保证约 99% 的时间段达到标称带宽」，标了「保证带宽」才是真正独享。看到 1Gbps 先别激动，先确认它是什么性质的 1Gbps。

## 常见问题

**月付还是年付？**
先月付。VPS 的体验高度依赖你所在地区、所在运营商、所在时段的实际表现，这些只有自己跑一遍才知道。确认稳定之后再考虑年付摊薄成本。LisaHost 的年付版省 350 元但有流量限制，算清楚再决定。

**1核1G 到底够不够？**
个人用途够。跑网站、写脚本、学 Linux、挂轻量服务，1核1G 都能胜任。跑 AI 应用、多开浏览器、装 Windows、跑数据库加面板加站点，直接上 2核2G 起。20GB 硬盘对多数人够用，但如果要存素材、备份、日志，40GB 更保险。

**新加坡和香港、日本怎么选？**
要国内访问快，选香港，延迟 30–60ms 的量级。要亚太覆盖、解锁日本流媒体、价格更实惠，选日本。要原生 IP 做跨境电商和社媒运营，选新加坡，但要接受中转。三者不是替代关系，是不同用途。

**KVM 和 OpenVZ 有什么区别？**
KVM 是完整虚拟化，每台机器有独立内核，可以自己改内核、装 Docker、跑 Windows。OpenVZ 共享宿主内核，便宜但限制多，很多操作做不了。LisaHost 全线 KVM。

**晚高峰卡怎么办？**
先确认是线路问题还是机器问题：换不同运营商网络测试，如果只有某一家运营商卡，是线路问题；如果全部卡，可能是带宽被挤占。线路问题只能换机房或换线路，机器问题可以升级配置。买之前用 48 小时退款窗口在晚高峰实测，比看任何评测都准。

**能不能装 Windows？**
官网标注支持安装 Windows。但 1G 内存跑 Windows Server 基本不可用，建议 4核4G 以上再考虑，且要确认授权问题。
